
# SDLx - An SDL2/SDL3 wrapper for PureBasic

⚠️ Work in progress! ⚠️

This is a single-file wrapper/helper library for easily using [libSDL](http://libsdl.org) within [PureBasic](http://purebasic.com).

The goal is not to wrap 100% of the SDL API, but a reasonable subset which is relevant to PureBasic and its supported platforms (Windows, Linux, Mac, Raspi).

The starting point was `SDL2.pbi`, but efforts have switched over to `SDL3.pbi` after SDL3 was officially released in 2025.

There is also an experimental wrapper `SDL3_net.pbi` for the related library [SDL3_net](https://wiki.libsdl.org/SDL3_net/CategorySDLNet).
